Broadcast Architecture

Designed specifically to handle heavy LAN event production without bogging down player PCs or requiring massive storage drives.

UDP/SRT Ingestion

Route multiple player POVs over your Gigabit switch directly from OBS using custom FFmpeg outputs. No HDMI cables required.

Rolling Memory Buffer

Continuously records temporary streams. Old segments are wiped automatically, ensuring zero hard drive bloat and max game FPS.

NLE Playback Deck

Set custom IN/OUT points on the fly, apply transitions, and manipulate playback speed for professional slow-motion highlights.

OBS WebSocket Synced

Automated scene routing. Live Forge triggers the OBS scene transition, plays the rendered clip, and instantly cuts back to live gameplay.

System Requirements

Network-based video routing relies heavily on your local infrastructure. Do not attempt to run multiple video streams on 100Mbps hardware.

LAN Infrastructure

  • Gigabit Switch (Mandatory) A 1000 Mbps unmanaged switch (e.g., TP-Link 24-Port Gigabit) is required. A standard 100 Mbps switch will crash under the bandwidth weight.
  • Cat6 Ethernet Cabling All player machines and the production PC must be hardwired with high-speed Cat6 cables.
  • Player Setup OBS Studio must be installed on player PCs to encode and transmit the UDP feed over the network.

Production PC

  • GPU (NVIDIA Recommended) An RTX 3050 or higher is highly recommended. Live Forge utilizes NVIDIA CUDA to decode up to 13 concurrent video streams smoothly.
  • Processor & RAM Intel Core i5 (12th Gen+) or AMD Ryzen 5 (5000 Series+) with at least 16GB RAM.
  • External SSD Storage A dedicated Type-C External SSD is required for the Video Buffer directory to prevent the operating system drive from bottlenecking.

Quick Start Guide

Follow these exact steps to prepare your production machine and player PCs for a live LAN event.

01

Install FFmpeg (Crucial)

Live Forge requires FFmpeg to process and render video clips. Download the latest Windows build of FFmpeg and either add it to your System PATH variables, or extract ffmpeg.exe and place it directly into the Live Forge installation folder.

02

Configure OBS WebSocket

On your main broadcast PC, open OBS Studio and go to Tools > WebSocket Server Settings. Check "Enable WebSocket server" (v5). Note your Port (usually 4455) and Server Password. Enter these credentials into the Live Forge Settings menu so the engine can control OBS.

03

Set Up Player UDP Streams

On every Player PC, open OBS, go to Settings > Output, set the Output Mode to Advanced, and configure a Custom Output (FFmpeg). Enter a unique UDP URL targeting your Production PC's IP address. Example:

udp://192.168.1.100:5001?pkt_size=1316

Add this exact URL to your Camera Profiles in Live Forge.

04

Buffer & Capture

Click "START BUFFERING" before the match begins. When a hype moment happens, press your assigned Hotkey (e.g., F10) to instantly extract the last 15 seconds. Prep the clip in the NLE deck, and click "Play in OBS" to send it live.
