Core Engine Features

Live Forge replaces messy HDMI splitters and expensive capture rigs with efficient, high-speed network routing.

UDP/SRT Network Ingestion

Instead of running HDMI cables from every player desk to a central switcher, players use OBS on their own computers to stream their POV directly over the local network. Live Forge catches these incoming streams seamlessly.

Rolling Memory Buffer

The engine constantly records incoming streams in small .ts chunk files. To prevent the production hard drive from crashing, Live Forge automatically deletes older chunks, maintaining a continuous 5-minute memory loop in the background.

Hardware Video Decoding

Processing 10 live video streams simultaneously will instantly bottleneck a CPU. The engine offloads the heavy video decoding directly to the NVIDIA GPU (CUDA) or Intel iGPU (QSV), maintaining system stability.

Global Hotkey Extraction

You do not need to manually scrub through footage. When a massive play happens, press a designated hotkey (F1-F15). The engine instantly extracts the last few seconds of action from the rolling buffer while the live game continues.

NLE Playback Deck

Once a clip is extracted, utilize the Non-Linear Editor deck to trim exact IN/OUT points, apply cross-dissolve transitions, and drop the playback speed to 50% or 25% for professional slow-motion replays.

OBS WebSocket Integration

Live Forge acts as a remote control for your main OBS broadcast. When you trigger a replay, the engine commands OBS to switch to a dedicated "Replay" scene, plays the video file, and automatically transitions back to the live desk.

Live Event Playbook

The exact, step-by-step operational guide for deploying Live Forge at a grassroots LAN tournament.

01

Hardware Infrastructure

Connect all player machines and the central Production PC to a Gigabit (1000 Mbps) unmanaged switch using Cat6 Ethernet cables.

Warning: A standard 100 Mbps switch will crash under the bandwidth load of multiple video feeds. True Gigabit routing is strictly mandatory.
02

Player PC Encoding

Open OBS Studio on each player's computer to establish the video feed.

1. Go to Settings > Output and set it to Custom Output (FFmpeg).
2. Set the Output Type to URL.
3. Direct the stream to the Production PC's IP address, assigning a unique port for each player. Set the keyframe interval to 1 or 2 so the footage can be cut cleanly.
udp://192.168.1.100:5001?pkt_size=1316
03

Engine Ingestion

Launch Live Forge on the primary Production PC.

Enter the matching UDP URLs from Step 2 into the Live Forge Camera Profiles. This allows the engine to lock onto the incoming player feeds across the local network.
04

OBS Synchronization

Link Live Forge to the OBS Studio instance handling the actual livestream.

1. On the Production PC's OBS, enable the WebSocket server on port 4455.
2. Create an OBS scene named exactly Replay with a Media Source pointing to the Live Forge output folder.
3. Input your OBS WebSocket password into the Live Forge settings tab.
05

Live Execution

Operate the replay system during the tournament broadcast.

Click START BUFFERING when the match begins. When a clutch round ends, press your assigned F-key, adjust the clip in the NLE deck, and click Play in OBS to instantly push the replay to the live stream.
