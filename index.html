Core Engine Features

Live Forge replaces messy HDMI splitters and expensive capture rigs with efficient, high-speed network routing.

UDP/SRT Network Ingestion

Instead of running HDMI cables from every player desk to a central switcher, players use OBS on their own computers to stream their POV directly over the local network. Live Forge catches these incoming streams seamlessly.

Rolling Memory Buffer

The engine constantly records incoming streams in small .ts chunk files. To prevent the production hard drive from crashing, Live Forge automatically deletes older chunks, maintaining a continuous 5-minute memory loop in the background.

Hardware Video Decoding

Processing 10 live video streams simultaneously will instantly bottleneck a CPU. The engine offloads the heavy video decoding directly to the NVIDIA GPU (CUDA) or Intel iGPU (QSV), maintaining system stability.

Global Hotkey Extraction

You do not need to manually scrub through footage. When a massive play happens, press a designated hotkey (F1-F15). The engine instantly extracts the last few seconds of action from the rolling buffer while the live game continues.

NLE Playback Deck

Once a clip is extracted, utilize the Non-Linear Editor deck to trim exact IN/OUT points, apply cross-dissolve transitions, and drop the playback speed to 50% or 25% for professional slow-motion replays.

OBS WebSocket Integration

Live Forge acts as a remote control for your main OBS broadcast. When you trigger a replay, the engine commands OBS to switch to a dedicated "Replay" scene, plays the video file, and automatically transitions back to the live desk.

Strict Hardware Tolerances

To prevent dropped frames, network stuttering, and stream desyncs, your physical event infrastructure must meet these minimum specifications.

Network Topology

  • Core Switch Layer A 1000 Mbps (Gigabit) unmanaged switch is strictly mandatory. A 10-player LAN pushing 10,000 Kbps each will instantly saturate and crash a 100 Mbps switch.
  • Physical Cabling Cat6 or Cat5e Ethernet cables only. Do not attempt to run UDP video streams over venue Wi-Fi.
  • IP Configuration Ensure all Player PCs and the Production PC are on the same subnet (e.g., 192.168.1.X) with no AP Isolation enabled on the router.

Production Rig

  • GPU Specifications NVIDIA RTX 3050, 3060, or 40-series required. The NVENC/NVDEC chips are critical for maintaining stream stability during multi-cam extraction.
  • Storage Bandwidth A dedicated USB 3.1 Type-C External SSD (e.g., Samsung T7) is required solely for the Video Buffer. Writing 10 continuous video streams to your OS Drive (C:) will cause system-wide lockups.
  • Processing Power Intel Core i5 (12th Gen+) or AMD Ryzen 5 (5000 Series+) with a minimum of 16GB dual-channel RAM.

Advanced Setup Guide

Exact configuration parameters to ensure the player video streams are readable by the Live Forge ingestion engine.

01

Player PC OBS Configuration

On every player's machine, open OBS Studio. Go to Settings > Output. Change the Output Mode to Advanced, navigate to the Recording tab, and apply these exact parameters:

Parameter Required Setting
Type Custom Output (FFmpeg)
FFmpeg Output Type Output to URL
File path or URL udp://[PRODUCTION_PC_IP]:[PORT]?pkt_size=1316
Container Format mpegts
Video Bitrate 8000 Kbps - 15000 Kbps (depending on switch capacity)
Keyframe interval 1 or 2 (Critical: High keyframes prevent trimming errors)
Video Encoder nvenc_h264 or h264_qsv (Hardware encoding only)
02

Connecting the Engine

On the Production PC, launch Live Forge. In the Camera Profile settings, add the corresponding UDP URLs that you configured on the Player PCs. Ensure you increment the ports for each player.

// Live Forge Camera URL Format Example udp://@0.0.0.0:5001 udp://@0.0.0.0:5002 udp://@0.0.0.0:5003

Live Event Playbook

The exact operational timeline for running Live Forge during a live LAN tournament broadcast.

01

Hardware Infrastructure

Connect all player machines and the central Production PC to your Gigabit switch using Cat6 Ethernet cables.

02

Player PC Encoding

Ensure OBS Studio is open on each player's computer and outputting the UDP stream to your Production PC's IP address.

03

OBS Synchronization

Link Live Forge to the OBS Studio instance handling the actual livestream.

1. On the Production PC's OBS, enable the WebSocket server on port 4455.
2. Create an OBS scene named exactly Replay with a Media Source pointing to the Live Forge output folder.
3. Input your OBS WebSocket password into the Live Forge settings tab.
04

Live Execution

Operate the replay system during the tournament broadcast.

Click START BUFFERING when the match begins. When a clutch round ends, press your assigned F-key, adjust the clip in the NLE deck, and click Play in OBS to instantly push the replay to the live stream.

Troubleshooting & FAQ

Common issues encountered during live tournament deployments.

The video buffer is stuttering or dropping frames.

This is almost always a network bottleneck. Ensure your switch is truly Gigabit (1000 Mbps). If the switch is Gigabit, verify that the Player PCs are using Cat6 cables. If cables are fine, lower the Player PC OBS Video Bitrate from 15000 Kbps down to 8000 Kbps.

When I extract a clip, the first few seconds are frozen.

This occurs when the Player PC's OBS has a Keyframe Interval set to 0 (Auto) or too high (e.g., 250). FFmpeg requires frequent keyframes to accurately cut `.ts` files. Ensure the Player PC OBS Keyframe Interval is hardcoded to 1 or 2.

Live Forge cannot connect to OBS WebSocket.

Verify that your Windows Defender Firewall is not blocking port 4455 on your Private Network. Additionally, ensure you have OBS WebSocket v5.x installed (it comes native with OBS v28 and higher; older versions use an incompatible v4 plugin).
