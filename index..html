LIVE FORGE

The open-source, network-based instant replay and broadcast engine designed for grassroots esports LAN tournaments.

Download for Windows View Source Code on GitHub

Network Video Ingestion

Pull 10+ player feeds simultaneously over a Gigabit switch using UDP/SRT. No expensive physical capture cards required.

Zero-Bloat Buffering

Captures a rolling memory loop. Players' local hard drives are never filled with massive video files, ensuring zero impact on game performance.

OBS Integration

Built-in WebSocket support automatically switches OBS scenes to play your replay, then cuts back to live gameplay seamlessly.
