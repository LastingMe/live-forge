Broadcast-Grade Architecture

Built to handle heavy LAN event production without bogging down player PCs.

🌊

UDP/SRT Ingestion

Players stream their POV directly over your local network using OBS custom FFmpeg output. No physical HDMI splitters, no capture cards, no messy cables at the player desks.

⚡

Zero-Bloat Buffering

Live Forge utilizes a rolling memory loop. Old video segments are automatically wiped from your drive. Players' hard drives are never touched, ensuring zero competitive lag.

🎬

vMix-Style NLE Editor

Don't just replay—produce. Select multiple camera angles, apply cut or dissolve transitions, and dial in the speed (10%, 25%, 50%) for professional slow-motion highlights.

🔌

OBS WebSocket Synced

The engine talks directly to OBS Studio. When you prep a clip and hit 'Play in OBS', Live Forge automatically fires the scene transition, plays the clip, and cuts back to live gameplay.

⌨️

Global Hotkeys

Never miss a clutch. Map your F1-F15 keys (or a custom macro pad) to instantly extract the last 5, 10, or 15 seconds of action while the game is still running.

⚙️

Hardware Accelerated

Designed for heavy lifting. Features native support for NVIDIA CUDA (NVDEC), Intel QSV, and Windows DXVA2 to decode 13+ concurrent video streams effortlessly.

System Requirements

Network-based video routing requires specific hardware infrastructure to remain stable.

Production Machine

  • OS Windows 10 / 11 (64-bit)
  • CPU Intel Core i5 (12th Gen+) or AMD Ryzen 5 (5000 Series+)
  • GPU NVIDIA RTX 3050 or higher (CUDA support is crucial for multi-stream decoding)
  • RAM 16GB Minimum (32GB Recommended for OBS compositing)
  • Storage Dedicated USB-C SSD for video buffer directories

LAN Infrastructure

  • Network Switch Gigabit Unmanaged Switch (1000 Mbps) is strictly mandatory. 100 Mbps switches will crash.
  • Cabling Cat6 Ethernet cables for all player and production machines
  • Player Setup OBS Studio installed to encode and transmit the UDP/SRT feed
  • Dependencies FFmpeg must be installed and added to the system PATH
